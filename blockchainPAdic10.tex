\section{Erläuterung}

In dieser Tabelle sind die Steuern eines 11-adischen Blocktrees dargestellt:

\begin{itemize}
\item \textbf{11 Dörfer pro Bundesland}  
\item \textbf{11 Bundesländer pro EU-Land}  
\item Steuern werden aufgeteilt in \textbf{Infrastruktur} und \textbf{Transfer}  
\item Transfers werden gleichmäßig auf alle 11 EU-Länder verteilt  
\end{itemize}

\section{Erklärung der Berechnung}

\begin{itemize}
\item \textbf{Dorfsteuer} = beliebiger Betrag (z.B. in Geldeinheiten)  
\item \textbf{Infrastruktur} = 60\% der Dorfsteuer  
\item \textbf{Transfer} = 40\% der Dorfsteuer  
\item \textbf{Summe Bundesland} = Summe aller Dörfer  
\item \textbf{EU-Verteilung} = Summe Transfers Bundesland $\div$ 11 EU-Länder  
\end{itemize}
