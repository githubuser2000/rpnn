# libreta_arch.so

Deutsch: Architektur-, Kategorie-, Topologie-, Morphismus- und universelle-Eigenschaftsgrenze.

English: Architecture, category, topology, morphism, and universal-property boundary.

This crate builds one dynamic `cdylib` and exports a small C ABI:

- `reta_arch_abi_version`
- `reta_arch_abi_anchor`
- `reta_arch_abi_library_name`
- `reta_arch_abi_crate_name`
- `reta_arch_abi_role_de` / `reta_arch_abi_role_en`
- `reta_arch_abi_math_de` / `reta_arch_abi_math_en`
- `reta_arch_abi_manifest_json`

The detailed German and English documentation is in:

- `doc/shared-libs/de/libreta_arch.md`
- `doc/shared-libs/en/libreta_arch.md`
